# Module 7: Broader AI Concepts
**Slide coverage:** 36-39

## Learning objectives
- Place ML within adjacent AI application domains.
- Identify common tasks in computer vision, NLP, recommendation, and generative AI.
- Link earlier foundations to modern AI system examples.

## Key formulas and concepts
- Recommendation concept framing:
  - `user behavior + item information -> recommendation`
- Generative AI framing:
  - learns patterns to produce new content (text, images, code, etc.)

## Teaching notes
- Keep this module broad and motivating rather than deep mathematically.
- Use local and familiar examples for each domain.
- Reinforce that the same ML workflow principles still apply.

## What students should be able to do
- Name a concrete use case per domain (CV, NLP, recsys, generative AI).
- Explain how data and objectives differ across these domains.
- Connect practical notebook exercises to larger AI product contexts.
