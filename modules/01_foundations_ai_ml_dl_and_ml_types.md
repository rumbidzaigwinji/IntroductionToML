# Module 1: Foundations (AI, ML, DL, and ML Types)
**Slide coverage:** 1-7

## Learning objectives
- Distinguish AI, Machine Learning, and Deep Learning.
- Explain why ML is different from rule-based programming.
- Identify supervised, unsupervised, and reinforcement learning setups.

## Key formulas and concepts
- Traditional programming: `Rules + Data -> Answers`
- ML framing: `Data + Answers -> Learned rules/model`
- Reinforcement learning objective: maximize cumulative reward `sum_t R_t`

## Teaching notes
- Position ML as pattern learning from data, not hard-coded logic.
- Show the set relationship: `AI ⊃ ML ⊃ DL`.
- Use one practical example per ML type:
  - Supervised: loan default prediction
  - Unsupervised: customer segmentation
  - Reinforcement learning: game/control policy

## What students should be able to do
- Correctly categorize a task as supervised, unsupervised, or RL.
- Explain in one sentence when deep learning is a subset of ML.
- Describe the data requirement differences across the three ML types.
