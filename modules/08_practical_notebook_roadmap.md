# Module 8: Practical Notebook Roadmap
**Slide coverage:** 40-42

## Learning objectives
- Understand how the practical sessions are sequenced.
- Know what “good completion” looks like for each notebook.
- Prepare for independent challenge work and leaderboard submission.

## Notebook sequence
1. `notebooks/01_intro_bike_demand_regression_instructor.ipynb`
2. `notebooks/02_bike_demand_regression_advanced_extension.ipynb`
3. `notebooks/03_challenge_bank_marketing_classification.ipynb`

## Key formulas and concepts revisited in practicals
- Regression metrics: MAE, RMSE, R^2
- Classification metrics: Precision, Recall, F1, ROC-AUC
- Competition ranking: PR-AUC primary, then F1, then log loss

## Teaching notes
- Start guided, then move to independent challenge.
- Emphasize reproducible pipelines and leakage detection.
- Use check cells as milestones, not as replacements for reasoning.

## What students should be able to do
- Run notebooks top-to-bottom from a clean kernel.
- Produce and compare model metrics correctly.
- Export challenge prediction probabilities in required format (`id,y_prob`).
