Foundations: Why ML, AI-ML-DL, and Learning Types

Why Machine Learning Exists

Traditional software engineering works best when the rules are explicit and stable. In many real-world tasks, those rules are too numerous or too complex to hand-code.

\[ \text{Rules + Data} \rightarrow \text{Answers} \]

Meaning: in normal programming, humans write explicit rules, then the computer uses those rules on data to produce answers.

Machine learning inverts this process by learning patterns from examples.

\[ \text{Data + Correct Answers} \rightarrow \text{Learned Rules (Model)} \]

Meaning: in ML, we feed example inputs and their true outputs, and the algorithm learns the rules automatically.

AI, Machine Learning, and Deep Learning

\[ \text{AI} \supset \text{ML} \supset \text{DL} \]

Meaning: deep learning is one part of machine learning, and machine learning is one part of AI.

  • Artificial Intelligence is the broad field of intelligent systems.
  • Machine Learning is a subset where systems learn from data.
  • Deep Learning is a subset using multi-layer neural networks.

Three Main Types of Learning

Learning Type What The Model Receives Example Task
Supervised Inputs with labels Predict house price
Unsupervised Inputs only, no labels Group customers by behavior
Reinforcement Rewards and penalties from actions Learn a game-playing policy

Supervised Learning Setup

\[ (x_i, y_i), \quad x_i=\text{features}, \quad y_i=\text{target label} \]

Meaning: each training row has input values (\(x_i\)) and the correct answer (\(y_i\)).

\[ f(x_i) \approx y_i \]

Meaning: the model function \(f\) should produce predictions close to the true label.

Students should understand that the model learns a mapping from input features to expected output labels.

Unsupervised Learning Setup

\[ x_1, x_2, x_3, \ldots, x_n \]

Meaning: in unsupervised learning we only have inputs, no target labels.

No labels are provided. The objective is to discover structure, clusters, latent groups, or unusual samples.

  • Clustering algorithms: K-Means, DBSCAN.
  • Dimensionality reduction: PCA.
  • Common applications: segmentation, anomaly detection, pattern discovery.

Reinforcement Learning Setup

\[ \text{State} \rightarrow \text{Action} \rightarrow \text{Reward} \]

Meaning: the agent sees a situation, takes an action, then receives feedback.

\[ \text{Objective: maximize } \sum_t R_t \]

Meaning: the goal is to maximize total reward over time, not just immediate reward.

The agent learns by interacting with an environment and improving behavior through cumulative reward.

Supervised Learning: Regression and Classification

Regression

Regression predicts a continuous numeric value.

\[ \hat{y} = f(x) \]

Meaning: prediction (\(\hat{y}\)) is produced by applying model \(f\) to input \(x\).

Common examples: house price, temperature, crop yield, sales demand.

Simple Linear Regression

\[ \hat{y} = wx + b \]

Meaning: linear regression predicts using a weighted feature plus a bias offset.

  • \(w\): slope/weight controlling sensitivity to \(x\)
  • \(b\): intercept/bias shifting predictions
  • \(x\): feature input
  • \(\hat{y}\): predicted output

Prediction Error

\[ \text{error}_i = y_i - \hat{y}_i \]

Meaning: this is how far one prediction is from the truth for sample \(i\).

Training algorithms seek parameters that reduce these errors across all training examples.

Classification

Classification predicts category labels instead of continuous values.

\[ \hat{y} \in \{0,1\} \quad \text{or} \quad \hat{y} \in \{1,\dots,K\} \]

Meaning: classification outputs belong to a fixed set of labels.

  • Binary classification: fraud/not fraud, spam/not spam.
  • Multiclass classification: species type, disease type, digit class.

Probability View of Classification

\[ P(y=1 \mid x) \]

Meaning: probability that the class is positive, given the input features.

The model outputs probability, then thresholding converts it to a class.

\[ \hat{y}=1 \quad \text{if} \quad P(y=1 \mid x) \ge \tau \]

Meaning: if probability is above threshold \(\tau\), predict class 1; otherwise predict class 0.

Threshold \(\tau\) should be chosen based on business cost trade-offs, not arbitrary defaults.

Logistic Regression: A First Classification Model

Logistic regression is a beginner-friendly model for binary classification. It predicts probabilities between 0 and 1.

\[ P(y=1 \mid x)=\sigma(z) \]

Meaning: probability of positive class is computed by applying sigmoid function to model score \(z\).

\[ z=w_1x_1 + w_2x_2 + \dots + w_dx_d + b \]

Meaning: \(z\) is a weighted sum of features plus bias.

\[ \sigma(z)=\frac{1}{1+e^{-z}} \]

Meaning: sigmoid squashes any real value into the range 0 to 1.

  • Probability near 1 means strong positive prediction.
  • Probability near 0 means strong negative prediction.
  • Thresholding converts probabilities into final class labels.
  • Logistic regression is fast, interpretable, and strong as a baseline.

Baselines: What Counts as a Good Model?

Before training advanced models, compare against a simple baseline. A baseline is a very simple prediction strategy used as a reference point.

Regression Baseline

Predict the average target value for every example.

  • If average bike demand is 120 rentals, baseline predicts 120 every time.
  • Useful model must outperform this simple strategy.

Classification Baseline

Predict the most common class for every example.

  • If 88% of customers do not subscribe, naive model predicts "no" for everyone.
  • High accuracy alone can hide poor usefulness.

A machine learning model is useful only when it performs meaningfully better than baseline.

Training Mathematics: Data, Loss, Objective, and Optimization

Dataset and Matrix Notation

\[ D=\{(x_1,y_1),(x_2,y_2),\dots,(x_n,y_n)\} \]

Meaning: \(D\) is the full training dataset made of input-output pairs.

\[ X \in \mathbb{R}^{n \times d}, \quad y \in \mathbb{R}^{n} \]

Meaning: \(X\) is a table with \(n\) rows and \(d\) features, and \(y\) is one target per row.

Here \(n\) is number of examples, \(d\) is number of features, \(X\) is the feature matrix, and \(y\) is the target vector.

Prediction Function and Parameters

\[ \hat{y}=f_{\theta}(x) \]

Meaning: model parameters \(\theta\) control how input is turned into predictions.

\(\theta\) contains learnable parameters. Training is parameter estimation.

Loss Function

\[ L(y,\hat{y}) \]

Meaning: loss function returns a number showing how wrong one prediction is.

A loss function quantifies error for each example. Lower loss means better fit to observed labels.

Example for regression:

\[ L(y,\hat{y})=(y-\hat{y})^2 \]

Meaning: squaring makes large mistakes count much more than small mistakes.

Training Objective (Empirical Risk)

\[ J(\theta)=\frac{1}{n}\sum_{i=1}^{n}L\left(y_i,f_{\theta}(x_i)\right) \]

Meaning: \(J(\theta)\) is average training error across all examples.

The model is trained by finding parameter values that minimize average loss.

Gradient Descent Update

\[ \theta \leftarrow \theta - \alpha \nabla_{\theta}J(\theta) \]

Meaning: update parameters by moving in the direction that reduces error.

  • \(\alpha\): learning rate (step size)
  • \(\nabla_{\theta}J(\theta)\): gradient of objective

Too small learning rate slows convergence; too large can cause unstable updates and divergence.

Evaluation: Choosing the Right Metrics

Why Evaluation Is Separate From Training

Good training performance does not guarantee real-world usefulness. Evaluation checks generalization on unseen data and reveals error behavior.

Regression Metrics

\[ \text{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i| \]

Meaning: average absolute distance between true and predicted values.

\[ \text{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2 \]

Meaning: average squared error; very large errors are penalized heavily.

\[ \text{RMSE}=\sqrt{\text{MSE}} \]

Meaning: square root returns the metric to original target units.

  • MAE is easy to interpret in original units.
  • MSE penalizes large errors strongly.
  • RMSE returns MSE scale back to target units.

Confusion Matrix for Classification

Predicted Positive Predicted Negative
Actual Positive TP FN
Actual Negative FP TN

Classification Metrics

\[ \text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN} \]

Meaning: percentage of all predictions that are correct.

\[ \text{Precision}=\frac{TP}{TP+FP} \]

Meaning: when model predicts positive, precision tells how often it is right.

\[ \text{Recall}=\frac{TP}{TP+FN} \]

Meaning: of all real positives, recall tells how many were found.

\[ F_1=2\cdot\frac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}} \]

Meaning: F1 balances precision and recall into one score.

Accuracy can be misleading in imbalanced datasets. Precision and recall should be chosen according to cost of false positives versus false negatives.

Beyond Accuracy: ROC-AUC and Precision-Recall

Classification performance changes as threshold changes, so we also evaluate ranking quality across many thresholds.

ROC Curve

ROC compares True Positive Rate and False Positive Rate.

\[ \text{TPR}=\frac{TP}{TP+FN}, \quad \text{FPR}=\frac{FP}{FP+TN} \]

Meaning: TPR tells how many real positives are found; FPR tells how often negatives are wrongly flagged.

ROC-AUC

ROC-AUC summarizes threshold-independent ranking quality. AUC of 1.0 is perfect ranking, 0.5 is near-random ranking.

Precision-Recall Curve

Precision-recall analysis is especially useful when positive class is rare. For imbalanced data, PR curves, ROC-AUC, precision, recall, and F1 are often more informative than accuracy.

Class Imbalance

Some classification datasets have far more examples of one class than another. In this case, naive models can appear accurate while being useless.

  • Example: 90% "no", 10% "yes" can yield 90% accuracy by predicting "no" always.
  • Inspect class proportions early before model training.
  • Use precision, recall, F1, ROC-AUC, and PR curves for evaluation.
  • Consider class weights or resampling strategies.
  • Choose thresholds using real error costs, not defaults only.

Data Cleaning and Feature Scaling

Why Cleaning Comes Before Modeling

Models learn directly from data quality. Missing values, duplicates, wrong dtypes, outliers, and inconsistent feature scales degrade model reliability.

\[ \text{Poor data} \rightarrow \text{Poor model} \]

Meaning: cleaning and preprocessing quality directly affects model quality.

Handling Missing Values

  • Drop rows or columns when missingness is extreme or unusable.
  • Impute with mean, median, mode, or context-aware group statistics.
  • Use model-based imputation when structure supports it.
  • Avoid leakage: fit imputation parameters on training set only.

Scaling Methods

\[ z=\frac{x-\mu}{\sigma} \]

Meaning: standardization centers feature values around zero with unit variance.

\[ x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}} \]

Meaning: min-max normalization rescales values into a 0 to 1 range.

Scaling is especially important for distance-based and gradient-based methods such as KNN, K-Means, Logistic Regression, and Neural Networks.

Feature Engineering and Encoding Categorical Variables

Many real datasets contain text categories like city, weather condition, job type, or education level. Most ML models require numeric features, so we must encode categories.

One-Hot Encoding

A category column is converted into binary indicator columns.

Color Red Blue Green
Red 1 0 0
Blue 0 1 0

Important warning: fit encoding on training data only, then apply same mapping to validation and test sets.

Pipelines: Preventing Leakage and Keeping Workflows Clean

A pipeline combines preprocessing and modeling into one repeatable process.

\[ \text{Impute Missing Values} \rightarrow \text{Scale Features} \rightarrow \text{Train Model} \]

Meaning: every split gets identical preprocessing and model steps.

Why Pipelines Matter

  • Apply preprocessing consistently across train, validation, and test data.
  • Reduce accidental leakage from validation/test into training steps.
  • Improve reproducibility and experiment tracking.
  • Integrate naturally with cross-validation and hyperparameter search.

End-to-End Workflow

\[ \text{Data} \rightarrow \text{Clean} \rightarrow \text{Split} \rightarrow \text{Train} \rightarrow \text{Evaluate} \rightarrow \text{Improve} \]

Meaning: ML is an iterative process, not a single train step.

Split Roles

  • Training set: estimate model parameters.
  • Validation set: compare models and tune hyperparameters.
  • Test set: one final unbiased estimate of generalization.

Fitting Patterns

  • Underfitting: poor training and poor test performance.
  • Good fit: strong training and strong test performance.
  • Overfitting: strong training but weak test performance.

Do not repeatedly tune on the test set.

Cross-Validation: More Reliable Model Evaluation

A single train-validation split can be misleading when that split happens to be unusually easy or unusually hard.

K-Fold Cross-Validation

  1. Split the data into \(K\) folds.
  2. Train on \(K-1\) folds.
  3. Validate on the remaining fold.
  4. Repeat until every fold has been validation once.
  5. Average all validation scores.

Cross-validation gives a more stable performance estimate, especially on smaller datasets.

Hyperparameter Tuning

Hyperparameters are settings chosen before training begins, such as tree depth, regularization strength, learning rate, or number of estimators.

Tuning Process

  1. Choose candidate values.
  2. Train models on training data.
  3. Compare using validation or cross-validation scores.
  4. Select the best configuration.
  5. Evaluate once on held-out test set.

The test set should not be used repeatedly during tuning.

Broader AI Domains

Computer Vision

  • Image classification, object detection, segmentation, recognition.
  • Examples: crop disease detection, traffic analysis, medical imaging.

Natural Language Processing

  • Text classification, translation, summarization, QA, chatbots.
  • Examples: customer feedback analysis, report summarization.

Recommendation Systems

\[ \text{User behavior + Item information} \rightarrow \text{Recommendation} \]

Meaning: recommendations combine who the user is and what each item represents.

  • Use cases: movies, products, music, news feed ranking.

Generative AI

  • Produces new text, images, code, audio, and video content.
  • Differs from predictive ML, which predicts labels or numeric values.

Responsible Machine Learning

A model can perform well overall while still failing specific groups of people. Responsible ML evaluates impact, not just performance metrics.

Questions To Ask

  • Who is represented in training data and who is missing?
  • Are errors distributed fairly across different groups?
  • Could false positives or false negatives cause disproportionate harm?
  • Is this prediction task appropriate and ethical in context?
  • Are we transparent about limitations and uncertainty?

Glossary

  • Feature: An input variable used by a model.
  • Target: The value or label the model tries to predict.
  • Model: A learned mapping from inputs to outputs.
  • Loss: A number measuring prediction error.
  • Metric: A quantity used to evaluate model performance.
  • Baseline: A simple reference model.
  • Overfitting: Strong training performance but weak unseen-data performance.
  • Underfitting: Failing to capture meaningful patterns.
  • Data leakage: Using information during training that would not exist in real deployment.
  • Cross-validation: Repeated evaluation across multiple train-validation splits.
