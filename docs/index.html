Course Overview

This course explains how ML works from first principles, then applies those ideas in notebooks. The key outcomes are:

  • Differentiate AI, ML, and Deep Learning clearly.
  • Know when to use regression vs classification.
  • Understand training objective, loss, and gradient descent intuition.
  • Choose the right evaluation metric for the business problem.
  • Run a complete end-to-end ML workflow on real data.

Module 1: Foundations (Slides 1-7)

What To Teach

  • Why ML: traditional programming is Rules + Data -> Answers, while ML is Data + Answers -> Rules.
  • Set relationship: AI includes ML, and ML includes Deep Learning.
  • Three ML types depend on feedback available to the model.

Types Of ML

  • Supervised: data with labels, example: predict house price.
  • Unsupervised: data without labels, example: group customers.
  • Reinforcement learning: reward signals, example: game-playing agent.

Core Formula

Maximize cumulative reward: sum_t R_t

Module 2: Supervised Learning (Slides 8-13)

Regression

  • Predicts continuous numeric values: price, temperature, demand.
  • Notation: y_hat = f(x)
  • Simple linear model: y_hat = w x + b
  • Error per sample: error_i = y_i - y_hat_i

Classification

  • Predicts categories (spam/not spam, fraud/not fraud).
  • Binary output: y_hat in {0,1}, multiclass: y_hat in {1,...,K}.
  • Probability framing: P(y = 1 | x).
  • Threshold decision example: if P(y=1|x) >= 0.5, classify as positive.

Module 3: Training Math (Slides 14-18)

Notation And Structure

  • Dataset: D = {(x_1, y_1), ..., (x_n, y_n)}
  • Matrix view: X in R^(n x d), y in R^n
  • Prediction function: y_hat = f_theta(x)

Loss And Objective

  • Loss compares prediction to truth: L(y, y_hat).
  • Training objective (empirical risk): J(theta) = (1/n) * sum_i L(y_i, f_theta(x_i)).

Gradient Descent Intuition

theta := theta - alpha * grad_theta J(theta)

  • alpha too small: learning is slow.
  • alpha too large: training can be unstable.

Module 4: Evaluation Metrics (Slides 19-29)

Regression Metrics

  • MAE = (1/n) * sum |y_i - y_hat_i| (easy to explain)
  • MSE = (1/n) * sum (y_i - y_hat_i)^2 (penalizes large errors)
  • RMSE = sqrt(MSE) (returns to original units)
  • R^2 measures explained variance

Classification Metrics

Confusion matrix terms: TP, TN, FP, FN

  • Accuracy = (TP + TN) / (TP + TN + FP + FN)
  • Precision = TP / (TP + FP)
  • Recall = TP / (TP + FN)
  • F1 = 2 * (Precision * Recall) / (Precision + Recall)

Teaching Emphasis

  • False positives costly -> emphasize precision.
  • False negatives costly -> emphasize recall.
  • Accuracy alone can mislead on imbalanced datasets.

Module 5: Data Cleaning and Scaling (Slides 30-32)

Why It Matters

Poor data -> poor model

  • Check missing values, outliers, duplicates, wrong data types.
  • Prepare categorical variables correctly before modeling.

Missing Values

  • Drop rows/columns where appropriate.
  • Impute with mean, median, mode, or context-aware strategy.
  • Avoid data leakage from test set into preprocessing decisions.

Scaling Formulas

  • Standardization: z = (x - mu) / sigma
  • Normalization: x' = (x - x_min) / (x_max - x_min)

Module 6: Workflow and Validation (Slides 33-35)

End-To-End Workflow

Data -> Clean -> Split -> Train -> Evaluate -> Improve

Data Splits

  • Train set: learn parameters.
  • Validation set: compare/tune model choices.
  • Test set: final unbiased evaluation.

Generalization Patterns

  • Underfitting: poor train and poor test performance.
  • Good fit: strong train and strong test performance.
  • Overfitting: strong train but weak test performance.
  • Rule: do not repeatedly tune on the test set.

Module 7: Broader AI Concepts (Slides 36-39)

Computer Vision

  • Image classification, object detection, segmentation.
  • Examples: crop disease detection, traffic analytics.

Natural Language Processing

  • Text classification, translation, summarization, chatbots.
  • Examples: customer feedback classification, report summaries.

Recommendation Systems

User behavior + Item information -> Recommendation

Generative AI

  • Generates new text, images, code, audio, and video.
  • Difference: predictive ML predicts labels/values; generative AI creates samples.

Module 8: Practical Roadmap (Slides 40-42)

Notebook Session Flow

  • Load dataset and inspect data quality.
  • Clean missing values and encode categorical variables.
  • Split data, train model, evaluate metrics.
  • Interpret model behavior and error patterns.

Exercise Style

  • Guided cells with missing parts for students to complete.
  • Validation cells check correctness.
  • Reasoning is required, not just passing checks.

Key Takeaways For Students

  • ML learns patterns from data and needs clean inputs.
  • Task type determines model type and metric selection.
  • Evaluation on unseen data is non-negotiable.
